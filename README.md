# Diabetic-Retinopathy---ViT
Developed a deep-learning model using MobileNetV2 to classify diabetic retinopathy severity from retinal fundus images.
Preprocessed high-resolution images with augmentation techniques to improve generalization on imbalanced datasets.
Implemented training pipeline with TensorFlow/Keras, achieving strong accuracy while maintaining lightweight inference.
Built an evaluation workflow using confusion matrix, precision/recall, and ROC curves to measure clinical reliability.
Packaged the model into a deployable format suitable for real-time screening applications in healthcare setups.
